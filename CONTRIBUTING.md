# 🤝 Contributing to PRISM64

We welcome contributions from psychologists, designers, and software engineers!

## Contribution Guidelines
1. **Fork the repository** and create a feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. **Commit your changes**:
   ```bash
   git commit -m "feat: add amazing feature"
   ```
3. **Push to the branch**:
   ```bash
   git push origin feature/amazing-feature
   ```
4. **Open a Pull Request**.

## Code Style
- Vanilla JavaScript (ES6+) without heavy frameworks for optimal performance.
- CSS Variables adhering to the design system in `assets/css/style.css`.
- Python standard library for backend endpoints.

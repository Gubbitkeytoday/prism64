# 🚀 คู่มือการนำ PRISM64 ขึ้น Render.com (ฟรี 24/7)

## ขั้นตอนง่ายๆ ใน 3 นาที:

### 1. อัปโหลดโปรเจกต์ขึ้น GitHub
1. สร้าง New Repository บน [GitHub.com](https://github.com) (เช่น ตั้งชื่อว่า `prism64`)
2. นำไฟล์ทั้งหมดในโฟลเดอร์นี้อัปโหลดขึ้น GitHub

### 2. นำขึ้น Render.com
1. เข้าไปที่ [Render.com](https://render.com) แล้วล็อกอินด้วย GitHub
2. กดปุ่ม **"New +"** ด้านขวาบน แล้วเลือก **"Web Service"**
3. เลือก Repository `prism64` ที่เพิ่งอัปโหลด
4. ตั้งค่าดังนี้:
   * **Name:** `prism64` (หรือชื่อที่คุณต้องการ)
   * **Runtime:** `Python 3`
   * **Build Command:** *(ปล่อยว่างไว้)*
   * **Start Command:** `python server_mcp.py`
   * **Instance Type:** `Free` ($0/month)
5. กดปุ่ม **"Deploy Web Service"**

🎉 **เสร็จสิ้น!** คุณจะได้ลิงก์เว็บไซต์แบบ `https://prism64.onrender.com` พร้อมใช้งานและเปิดออนไลน์ 24/7 ทันที!
